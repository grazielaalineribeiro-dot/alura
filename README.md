# Meu Blog Tech

Projeto desenvolvido durante a atividade da Alura sobre criação de páginas web.

## 📚 Sobre o projeto

Este projeto consiste em uma página de blog sobre tecnologia e programação.

A página apresenta:

- Um cabeçalho com o nome do blog;
- Uma descrição do blog;
- Cards com publicações;
- Imagens relacionadas à tecnologia;
- Informações sobre o autor;
- Botões de interação;
- Layout responsivo para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
